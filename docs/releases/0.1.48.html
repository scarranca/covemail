Your AI keys stay put

  • Fixes an issue in 0.1.47 where AI provider and TypeSafe keys could disappear the first time Cove used them, so Jev and AI writing asked for a key that had just been saved.
  • Settings now confirms a TypeSafe key was actually stored before showing “Credentials saved”.

If you used 0.1.47, re-enter your TypeSafe key and any AI provider API keys once in Settings. Your Google connection, mail and learned voice were not affected.
