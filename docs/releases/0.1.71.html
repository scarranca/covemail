Sign-in codes, one click away

  • When a verification or sign-in code arrives, Cove shows it in the menu bar for ten minutes. Click it to copy it.
  • A notification with Copy can show the code too (Settings → Menu bar → Sign-in codes).
  • New mail arrives sooner: between full syncs, Cove checks for new mail every 30 seconds (every minute on battery).
  • Only the code is taken from the email, and only from mail that arrived in the last ten minutes.
  • iPhone: a code gets its own notification with Copy, even when notifications are set to Important.
